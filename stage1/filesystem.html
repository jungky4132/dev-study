파일 시스템과 inode 한 장 그림

파일 시스템이 하는 일, 리눅스 디렉터리 계층, 디렉터리 항목 · inode · 데이터 블록, 인덱스 할당 · STAGE 1 운영체제

핵심 정리

  • 파일 시스템은 디스크 블록을 파일 · 디렉터리 단위로 관리한다
  • 리눅스는 / 아래 하나의 트리: /etc 설정, /var/log 로그, /home 사용자, /dev 장치
  • 디렉터리 = (이름 → inode 번호) 목록, inode = 권한 · 소유자 · 크기 · 블록 위치 (이름은 없음)
  • 읽기 순서: 디렉터리에서 inode 번호 → inode에서 블록 위치 → 데이터 블록
