메모리 계층과 캐시 한 장 그림

레지스터 · 캐시(L1 · L2 · L3) · RAM · 보조기억장치, 캐시 히트와 미스, 참조 지역성 · STAGE 1 컴퓨터 시스템

핵심 정리

  • 메모리 계층: 레지스터 → L1 → L2 → L3 → RAM → 보조기억장치 (위로 갈수록 빠르고 작고 비쌈)
  • CPU는 캐시부터 찾고, 있으면 히트(빠름) · 없으면 미스(RAM에서 가져와 캐시에 복사)
  • 참조 지역성(시간 · 공간) 때문에 작은 캐시도 적중률이 높다
  • 캐시가 빠른 이유: CPU 칩 안에 있어 가깝고, 지역성 덕에 자주 맞는다
